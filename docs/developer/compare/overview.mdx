This page compares Spree with three other open-source commerce backends: [Medusa](/developer/compare/medusa), [Saleor](/developer/compare/saleor) and [Vendure](/developer/compare/vendure). It is written for developers and coding agents choosing a backend.

<Info>
  Facts about Medusa, Saleor and Vendure are **as of November 2026**. Each one links to the official repository, package or documentation it comes from, so you can check it. Projects change quickly. If a fact here is out of date, please [open an issue](https://github.com/spree/spree/issues).
</Info>

## Summary

- **Pick Spree** if you want REST APIs with typed TypeScript clients, a built-in multi-vendor marketplace, B2B pricing and companies, and an MCP server that can change data, all under permissive licences.
- **Pick Medusa** if your team wants one language (TypeScript) across backend and frontend, and you want quotes and order approvals in an open-source B2B starter.
- **Pick Saleor** if you want a GraphQL API, a Python and Django backend, and several channels with their own currency and warehouses in one open-source installation.
- **Pick Vendure** if you want a GraphQL API on Node.js and NestJS, the widest choice of databases, and are comfortable with GPLv3 or a commercial licence.

## What "one store per installation" means

An open-source Spree installation runs one store. That store can still sell in many places:

- **Sales channels** — online, point of sale, wholesale, a mobile app. Each has its own product assortment and access rules. See [Channels](/developer/core-concepts/channels).
- **Markets** — regions with their own currency, languages and prices. See [Markets](/developer/core-concepts/markets).

Separate brands or businesses with separate data need separate stores. In open source, that means separate installations. Spree Enterprise adds [multi-tenancy](/developer/multi-tenant/quickstart), which runs many isolated stores in one installation.

Saleor and Vendure channels, and the Medusa Store module, let one open-source installation hold several storefronts. If you need that without a commercial licence, they are a better fit.
