## Payments

<CardGroup>
  <Card title="Stripe" href="/integrations/payments/stripe" img="/images/integrations/logos/stripe.png">
    Stripe is a popular payment gateway that allows you to accept payments from your customers. Credit cards, wallets, buy-now-pay-later, installment payments and more.
  </Card>
  <Card title="Adyen" href="/integrations/payments/adyen" img="/images/integrations/logos/adyen.png">
    Adyen is a global payment platform that enables businesses to accept payments across multiple channels and markets. Credit cards, digital wallets, BNPL, local payment methods, and more across 150+ currencies.
  </Card>
  <Card title="PayPal" href="/integrations/payments/paypal" img="/images/integrations/logos/paypal.png">
    PayPal is an online payment system that allows you to send and receive money around the world. You can link your credit card, debit card, or bank account. You can also set up a PayPal Balance account.
  </Card>
  <Card title="RazorPay" href="/integrations/payments/razorpay" img="/images/integrations/logos/razorpay.png">
    Razorpay is a secure payment gateway that enables businesses to accept online payments via cards, UPI, net banking, and wallets. It also supports international transactions across multiple currencies.
  </Card>
</CardGroup>

## Emails

Spree sends transactional email over plain SMTP, so any provider works with the same environment variables. See [Emails](/developer/providers/emails) for the configuration and how to choose between them.

<CardGroup>
  <Card title="Resend" href="/integrations/email/resend" icon="mail">
    Developer-focused transactional email with a fast setup — add a domain, create an API key, and send.
  </Card>
  <Card title="Postmark" href="/integrations/email/postmark" icon="mail">
    Built specifically for transactional email, keeping order and account mail apart from bulk sending.
  </Card>
  <Card title="SendGrid" href="/integrations/email/sendgrid" icon="mail">
    A long-established platform for high volume, with detailed analytics and deliverability tooling.
  </Card>
  <Card title="Mailgun" href="/integrations/email/mailgun" icon="mail">
    Flexible routing with a choice of US or EU infrastructure for stores that keep email data in Europe.
  </Card>
  <Card title="Amazon SES" href="/integrations/email/amazon-ses" icon="mail">
    The cheapest option at volume, and the natural fit for a store already running on AWS.
  </Card>
</CardGroup>
