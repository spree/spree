---

Seller requirements are **the checklist sellers complete before they can be approved**. Each item appears on the seller's own onboarding checklist, and the required ones gate approval.

To reach it, navigate to **Settings → Seller requirements**, under the **Marketplace** group.

## What's on the screen

A drag-ordered list of requirements — the order you set here is the order sellers work through. There is no sort control; drag the handle to reorder.

A new store starts with five requirements, each marked **Required** and **Active**:

- **Accept terms**
- **Complete profile**
- **Billing address**
- **Returns address**
- **Minimum products**

## Add a requirement

Click **Add requirement**. The panel opens with a single **Type** dropdown, reading *"Choose what to ask for."* It offers the kinds not already in use:

- **Delivery method**
- **Shipping box**
- **Payout account**
- **Required custom fields**
- **Seller policy**
- **Seller confirmation**
- **Manual check**
- **Document**

## Edit a requirement

Opening a requirement gives you three settings:

| Setting | What the screen says |
|---|---|
| **Name** | *"What the seller sees on their checklist."* |
| **Required** | *"Required items must be done before a seller can be approved. Others are shown as recommended."* |
| **Active** | *"Switch off to stop asking for this without deleting it."* |

## Good to know

- A requirement type can only be used once, so the **Add requirement** list shrinks as you add them.
- Switching a requirement to inactive retires it without losing the record of sellers who already completed it.
- Marking an item **Required** is what gates approval — anything left unrequired is shown to the seller as recommended.
